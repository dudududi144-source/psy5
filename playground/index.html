🏗️ Foundation Architecture

The Foundation Architecture provides the core building blocks for the PSY6 engine:

  • Music Theory: motif.mjs, planner.mjs, policy.mjs, memory.mjs, context.mjs
  • Learning System: musical-learning.ts, learner.ts, policy.ts, store.ts
  • Composition Engine: composition-engine.ts, learning-kernel.ts
  • Transport System: transport.ts, v1-transport.ts
  • DSP Package: effects.ts, envelopes.ts, filters.ts, oscillators.ts, voicePool.ts
  • Analysis Package: analyzer.ts, dsp.ts, features.ts, inference.ts, onset.ts, pitch.ts, tempo.ts
  • Scheduler Package: scheduler.ts, rng.ts, types.ts
  • Material Package: material.ts, factory.ts, seed.ts, types.ts
  • Protocol Package: channel.ts, events.ts, state.ts
  • Device SDK: device.ts, host.ts, reference.ts

All files are located in the foundation/ directory.
